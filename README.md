# portfolio_3.0

Personal portfolio for **Ahmed Škulj** — Frontend Developer, Bosnia and Herzegovina.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript** and **Tailwind CSS v4**.
Black page, white type, Nunito Sans.

---

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build      # production build (type-checks as part of the build)
npm start          # serve the production build
npm run typecheck  # tsc --noEmit, useful in CI or a pre-commit hook
```

Requires Node.js 20.9 or newer.

## Add your photo

1. Put your image in `public/` — for example `public/profile.jpg`.
2. Open `src/data/content.ts` and change one line:

```ts
photo: "/profile.jpg",
```

A portrait crop (4:5) works best. The image is shown in black and white and
returns to full colour on hover — if you'd rather keep it in colour, delete
`grayscale` from the `className` in `src/components/About.tsx`.

## Edit your content

Everything on the page — text, jobs, schools, skills, links, hobbies —
lives in a single typed file:

```
src/data/content.ts
```

You should never need to open a component to change your content. Because each
export is typed, your editor autocompletes the fields and flags a missing or
misspelled one before you run anything.

| What you want to change | Export | Type |
| --- | --- | --- |
| Name, role, intro, bio, hobbies, photo | `person` | `Person` |
| Instagram / LinkedIn / GitHub links | `socials` | `Social[]` |
| Jobs | `experience` | `Job[]` |
| Schools | `education` | `School[]` |
| Skills | `skills` | `SkillGroup[]` |
| Nav items | `nav` | `NavItem[]` |

One thing worth knowing: `SocialLabel` is a union of `"GitHub" | "LinkedIn" | "Instagram"`,
and `iconFor` in `src/components/Icons.tsx` is a `Record<SocialLabel, …>`. Add a
fourth network to `socials` and TypeScript will refuse to build until you add its
icon — no silently missing icon at runtime.

## Change the font

The font is defined in exactly one place: `src/lib/fonts.ts`.

```ts
import { Nunito_Sans } from "next/font/google";

export const appFont = Nunito_Sans({
  subsets: ["latin", "latin-ext"],
  weight: ["400", "600", "700", "900"],
  display: "swap",
  variable: "--font-app",   // keep this name
});
```

To switch fonts, change the import and the function call — for example
`import { Manrope } from "next/font/google"` and `Manrope({ ... })`. Keep
`variable: "--font-app"` and everything updates automatically.

Keep `latin-ext` in `subsets` so Bosnian characters (Š, ć, č, ž, đ) render.

## Change the colours

All colours are tokens at the top of `src/app/globals.css`:

```css
@theme {
  --color-ink: #000000;                     /* page background */
  --color-surface: #0b0b0b;                 /* raised blocks */
  --color-paper: #fafafa;                   /* primary text */
  --color-dim: #808080;                     /* secondary text */
  --color-line: rgba(250, 250, 250, 0.14);  /* hairlines */
}
```

Tailwind v4 turns each token into utilities automatically (`bg-ink`, `text-paper`,
`border-line`, …). To flip the site to a light theme, swap `--color-ink` and
`--color-paper`.

## Structure

```
src/
├── app/
│   ├── layout.tsx       metadata, font variable, skip link
│   ├── page.tsx         section order
│   ├── globals.css      design tokens + base styles
│   ├── sitemap.ts       /sitemap.xml
│   └── robots.ts        /robots.txt
├── components/
│   ├── Header.tsx       fixed nav, highlights the section you're in
│   ├── Hero.tsx         name, intro, socials
│   ├── Section.tsx      shared shell: sticky label left, content right
│   ├── About.tsx        photo, bio, hobbies, languages
│   ├── Experience.tsx   job timeline
│   ├── Skills.tsx       three skill groups
│   ├── Education.tsx    schools
│   ├── Contact.tsx      email + social links
│   ├── Footer.tsx
│   ├── Reveal.tsx       scroll-triggered fade (client component)
│   └── Icons.tsx        inline SVG icons, no icon library
├── data/content.ts      ← all your content, plus the types
└── lib/fonts.ts         ← the font
```

`next-env.d.ts` is generated by Next on every build and is gitignored — don't
edit it or commit it.

## Before you deploy

Search for `ahmedskulj.com` and replace it with your real domain in:

- `src/app/layout.tsx` (`siteUrl`)
- `src/app/sitemap.ts`
- `src/app/robots.ts`

Optional: add `public/og.png` (1200×630) and reference it under `openGraph.images`
in `src/app/layout.tsx` so links unfurl with an image.

## Deploy

Push the repo to GitHub, import it at [vercel.com/new](https://vercel.com/new),
and deploy — no configuration needed. Netlify and Cloudflare Pages also work with
`npm run build`.

## Notes

- `strict: true` is on, and the build type-checks, so a type error fails the build.
- TypeScript is pinned to `^5.9.3`. TypeScript 7 is out, but 5.x is what editor
  tooling and the wider ecosystem are settled on — upgrade whenever you like,
  nothing here depends on 5-only behaviour.
- Accessibility: skip link, visible focus rings, real landmarks, `prefers-reduced-motion` respected.
- No `localStorage`, no analytics, no tracking.
- Three runtime dependencies: `next`, `react`, `react-dom`.
