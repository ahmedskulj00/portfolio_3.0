# portfolio_3.0

Personal portfolio for **Ahmed Škulj** — Frontend Developer, Bosnia and Herzegovina.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript** and **Tailwind CSS v4**.
Black page, white type, Nunito Sans.

---

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build      # production build (type-checks as part of the build)
npm start          # serve the production build
npm run typecheck  # tsc --noEmit, useful in CI or a pre-commit hook
```

Requires Node.js 20.9 or newer.
